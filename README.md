# ПДД · Городская автошкола

Первый веб-прототип тренажёра вождения. Сначала веб, Android — после стабилизации веб-версии.

## Запуск

Node.js 24 LTS (Node.js 22.18+ также поддерживает тесты без отдельного TS-раннера).

```sh
npm ci
npm run dev
```

```sh
npm test
npm run build
```

Результат сборки — `dist/`. Это статическое приложение, сервер приложений не требуется. Для игры нужен браузер с WebGL 2. Телефон держать горизонтально.

## Версия 0.2 — регулируемый перекрёсток

- Карта как данные (`roads.ts`): подходы к перекрёстку, стоп-линии, светофоры, переходы, зоны ограничения скорости. Разметка и светофоры в 3D строятся из тех же данных, что использует судья.
- Светофор с фазами: красный+жёлтый, зелёный, мигающий зелёный, жёлтый, красный; лампы в 3D переключаются по логическому состоянию.
- Судья поездки: ремень, превышение скорости, проезд стоп-линии на запрещающий сигнал, жёлтый при возможности остановиться, поворот без указателя, выезд с проезжей части, столкновение. Каждое нарушение — один раз на эпизод, с объяснением и пунктом ПДД.
- Сценарный трафик на поперечной улице: держит дистанцию, стоит на красный, тормозит перед игроком, виден в зеркалах.
- Урок 2 «Регулируемый перекрёсток», выбор занятия, индикатор светофора в HUD, журнал поездки и результаты уроков в прогрессе.

Ссылки на ПДД нужно сверить с актуальной официальной редакцией до публикации.

## Версия 0.1

- Квартал и учебная площадка из примитивов; парковка, конусы, здания, деревья и базовые дорожные ориентиры.
- Упрощённая модель движения с фиксированным шагом 60 Гц, АКПП P/R/N/D, тормоз, газ, ползучий ход и ручник.
- Защита от включения P/R на скорости и требование тормоза для переключения направления/выхода из P.
- Руль жестом, мультитач через Pointer Events, клавиатура; поворотники и ремень.
- Кабина, третье лицо, кнопки обзора, три зеркала с камерами и кэшируемыми render target текстурами.
- Визуальный крен и клевок, не меняющие коллайдер.
- Первый урок: подготовка → трогание → остановка в зоне → ручник и P.
- Теория: 6 оригинальных вводных вопросов с разбором. Это не официальная база экзаменационных билетов.
- Прогресс и настройки в localStorage; при уходе в теорию 3D-отрисовка приостанавливается.

## Управление

| Действие | Клавиши |
| --- | --- |
| Газ / тормоз | W / S или ↑ / ↓ |
| Руль | A / D или ← / → |
| P / R / N / D | 1 / 2 / 3 / 4 |
| Ручник | Пробел |
| Ремень | B |
| Поворотники | Q / E |
| Камера | C |
| Пауза | Esc |

На телефоне удерживайте тормоз одним пальцем, а другим выберите D. Снимите ручник, отпустите тормоз и нажмите газ. Руль вращается относительно центра; после отпускания возвращается плавно.

## Архитектура и ограничения

`src/game/vehicle.ts` — чистая модель движения и SAT-пересечения автомобиля с прямоугольными препятствиями. `lesson.ts` — уроки как данные. `roads.ts` — карта перекрёстка и зон. `signals.ts` — фазы светофора от времени симуляции. `rules.ts` — журнал событий и нарушений. `traffic.ts` — сценарные машины (IDM). `engine.ts` — Three.js, игровой цикл, камеры и ввод. `world.ts` — процедурная сцена. Vue управляет HUD, уроком, теорией и настройками.

Физика сейчас упрощённая: плоская поверхность, без подвески и Rapier. Касание здания или припаркованной машины останавливает автомобиль. Конусы пока визуальные. Трафик только на поперечной улице и телепортируется на её концах; уступания, пешеходов и разметки полос пока нет.

Модель содержит тормозную блокировку селектора для удобства обучения, не претендуя на точную инструкцию для всех реальных АКПП. Полные правила, трамваи, регулировщик и официальные билеты — следующие этапы: [план разработки](docs/DEVELOPMENT_PLAN.md).

## Проверки

Тесты покрывают блокировки селектора, торможение, задний ход, устойчивость шага симуляции, столкновения, порядок прохождения уроков, цикл светофора, данные карты, нарушения (допустимый случай, нарушение, пограничный жёлтый, повторное пересечение) и поведение трафика у стоп-линии. Браузерная проверка: вкладки, ответы и пояснения, сохранение прогресса. Тестовый облачный браузер не предоставляет WebGL: визуальная проверка 3D и мультитач на физическом телефоне пока не подтверждены.
