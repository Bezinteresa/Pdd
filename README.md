# ПДД · Городская автошкола

Первый веб-прототип тренажёра вождения. Сначала веб, Android — после стабилизации веб-версии.

## Запуск

Node.js 24 LTS (Node.js 22.18+ также поддерживает тесты без отдельного TS-раннера).

```sh
npm ci
npm run dev
```

```sh
npm test
npm run build
```

Результат сборки — `dist/`. Это статическое приложение, сервер приложений не требуется. Для игры нужен браузер с WebGL 2. Телефон держать горизонтально.

## Версия 0.1

- Квартал и учебная площадка из примитивов; парковка, конусы, здания, деревья и базовые дорожные ориентиры.
- Упрощённая модель движения с фиксированным шагом 60 Гц, АКПП P/R/N/D, тормоз, газ, ползучий ход и ручник.
- Защита от включения P/R на скорости и требование тормоза для переключения направления/выхода из P.
- Руль жестом, мультитач через Pointer Events, клавиатура; поворотники и ремень.
- Кабина, третье лицо, кнопки обзора, три зеркала с камерами и кэшируемыми render target текстурами.
- Визуальный крен и клевок, не меняющие коллайдер.
- Первый урок: подготовка → трогание → остановка в зоне → ручник и P.
- Теория: 6 оригинальных вводных вопросов с разбором. Это не официальная база экзаменационных билетов.
- Прогресс и настройки в localStorage; при уходе в теорию 3D-отрисовка приостанавливается.

## Управление

| Действие | Клавиши |
| --- | --- |
| Газ / тормоз | W / S или ↑ / ↓ |
| Руль | A / D или ← / → |
| P / R / N / D | 1 / 2 / 3 / 4 |
| Ручник | Пробел |
| Ремень | B |
| Поворотники | Q / E |
| Камера | C |
| Пауза | Esc |

На телефоне удерживайте тормоз одним пальцем, а другим выберите D. Снимите ручник, отпустите тормоз и нажмите газ. Руль вращается относительно центра; после отпускания возвращается плавно.

## Архитектура и ограничения

`src/game/vehicle.ts` — чистая модель движения и SAT-пересечения автомобиля с прямоугольными препятствиями. `lesson.ts` — проверка первого урока. `engine.ts` — Three.js, игровой цикл, камеры и ввод. `world.ts` — процедурная сцена. Vue управляет HUD, уроком, теорией и настройками.

Физика сейчас упрощённая: плоская поверхность, без подвески и Rapier. Касание здания или припаркованной машины останавливает автомобиль. Конусы пока визуальные; трафика и проверки сложных ПДД нет. Светофоры — статические ориентиры, а не законченная система регулирования. Ограничение скорости в HUD реализовано для одного учебного отрезка, без штрафов.

Модель содержит тормозную блокировку селектора для удобства обучения, не претендуя на точную инструкцию для всех реальных АКПП. Полные правила, трамваи, регулировщик и официальные билеты — следующие этапы: [план разработки](docs/DEVELOPMENT_PLAN.md).

## Проверки

Тесты покрывают блокировки селектора, торможение, задний ход, устойчивость шага симуляции, столкновения и порядок прохождения урока. Браузерная проверка: вкладки, ответы и пояснения, сохранение прогресса. Тестовый облачный браузер не предоставляет WebGL: визуальная проверка 3D и мультитач на физическом телефоне пока не подтверждены.
